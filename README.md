# Dynamic Todo List App

A clean, interactive todo list app built with plain HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Mark tasks as complete or incomplete
- Remove individual tasks
- Filter by all, active, and completed items
- Clear completed tasks
- Persistence using `localStorage`
- Responsive design for desktop and mobile

## Run locally

Open `index.html` in a browser, or serve the folder with a simple local web server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html` – app structure
- `styles.css` – styling and layout
- `script.js` – task logic and local storage
